Установка

Сборки без цифровой подписи.

Windows — «Подробнее → Выполнить в любом случае» в SmartScreen.

macOS — правый клик по файлу → «Открыть» в обход Gatekeeper.

Android — разрешите установку из этого источника.

Google Диск — для файлов больше 100 МБ сначала покажет «Не удалось проверить файл на вирусы»: нажмите «Всё равно скачать».

Список версий обновляется автоматически каждые 15 минут.
